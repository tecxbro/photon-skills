# Spectrum API: whatsapp-business

Manage WhatsApp Business onboarding and project configuration from the current tag. Protect Meta tokens, app secrets, phone-number IDs, and registration data. Use Spectrum or the low-level WhatsApp SDK for runtime messaging.

For every request, consult the current OpenAPI and record:

- HTTP method and path;
- authentication;
- required path, query, and body fields;
- response envelope;
- pagination and rate-limit behavior;
- destructive, paid, or secret-bearing effects;
- related CLI and SDK surface.

Official OpenAPI: <https://spectrum.photon.codes/openapi/json>
