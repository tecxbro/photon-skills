# Slack provider

- Configure one or more workspaces through current app configuration and installation credentials.
- Keep bot, refresh, signing, and client secrets out of logs.
- Resolve channels and direct conversations through documented methods.
- Narrow for Slack-specific message and event fields.
- Refresh expiring tokens through the provider’s current lifecycle.
- Treat unsupported generic features explicitly.
