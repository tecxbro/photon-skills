# iMessage troubleshooting

- Check credentials, line state, route binding, address normalization, and provider logs.
- Check local macOS permissions only for the local provider.
- Enable documented opt-in traces when Photon support needs the message path.
- Do not rotate credentials or remove lines merely to diagnose a read-only failure.

Official source: <https://photon.codes/docs/spectrum-ts/troubleshooting/imessage>
