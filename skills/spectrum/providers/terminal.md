# Terminal provider

Use Terminal as the local development and test harness for the same Spectrum message loop used in production.

Cover:

- current provider installation and configuration;
- slash commands;
- multiple Spaces;
- reactions and replies;
- file attachments and inline images;
- typing indicators;
- console capture without corrupting the TUI;
- deterministic local testing before enabling a paid or external provider.

Do not fork the agent logic into a terminal-only handler.

- <https://photon.codes/docs/spectrum-ts/providers/terminal/setup-and-usage>
- <https://photon.codes/docs/spectrum-ts/providers/terminal/interactions>
