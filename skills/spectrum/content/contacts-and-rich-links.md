# Contacts and rich links

- Create contacts from structured data, Spectrum Users, or vCards.
- Parse and serialize vCards only with current helpers.
- Use rich links to let each provider render its native preview.
- Treat rich-link metadata as potentially lazy and provider-dependent.
- Do not embed private contact fields that the user did not intend to share.
