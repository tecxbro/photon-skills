# Rename, avatar, and membership

- Rename only supported group conversations.
- Set or clear avatars with documented media inputs.
- Add or remove members only after resolving group capability.
- Leaving a Space is destructive and requires explicit user intent.
- Handle inbound group-change events idempotently.
